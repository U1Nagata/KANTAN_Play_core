# Firmware Archive

This directory preserves historical OTA binaries that are no longer used by the normal
build or update flow.

- `ota/core2/`: versioned KANTAN Play Core2 OTA binaries
- `ota/cores3/`: versioned KANTAN Play CoreS3 OTA binaries
- `ota/legacy/`: legacy generic OTA binary names

Current distribution files are deliberately kept outside this archive:

- `docs/firmware/`: GitHub Pages catalog and ESP Web Tools binaries
- `ota_bin/`: current OTA artifacts produced by the build

Do not reference archived filenames from firmware code or public installation pages.
