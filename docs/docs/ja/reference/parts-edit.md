# パートの編集

かんぷれには6つのパート（楽器トラック）があります。それぞれ音色・パターン・音量などを個別に設定できます。

## パート編集の開始

以下のいずれかの方法でパート編集メニューを開きます：

- 画面のパートアイコンを**長押し**
- シフトレバーを押し込みながら**1〜6のボタン**を押す

## パート簡易編集メニュー

| 番号 | 項目 | 説明 |
|---|---|---|
| 1 | 音色 | 楽器音色を選ぶ（下記カテゴリ参照） |
| 2 | パターン | 演奏パターンを選ぶ |
| 3 | 音量 | このパートの音量 |
| 4 | 左右バランス | ステレオの左右バランス |
| 5 | オクターブ | 音域をオクターブ単位でずらす |
| 6 | コード変更時の動作 | コードが変わったときのノートの扱い |
| 7 | パターン編集 | パターンを詳細編集 |
| 8 | コピー/ペースト | パート設定を他のスロット/パートにコピー |
| 9 | ノートをクリア | このパートのノートデータを削除 |
