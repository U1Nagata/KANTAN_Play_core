# スロットの使い方

スロットは演奏パターンのまとまりです。スロットごとに音色・パターン・キー・演奏モードを設定できます。

## スロットの切り替え

**スロットボタン**（最上段4つ）を押してスロットを切り替えます。

スロットボタンにはそれぞれ特定のスロット番号へのジャンプが割り当てられており、カスタマイズ可能です。

## スロット数の設定

最大64スロットまで設定できます：

**[Menu 5-2-1] 編集 → スロット設定 → スロット数**

## スロットの設定項目

**[Menu 5-2] 編集 → スロット設定** から各項目を設定できます：

| 番号 | 項目 | 説明 |
|---|---|---|
| 1 | スロット数 | このソングで使うスロットの総数（最大64） |
| 2 | 演奏モード | コード / ノート / ドラム |
| 3 | キー転調 | このスロットだけキーをずらす量 |
| 4 | ステップ／ビート | 1拍あたりの裏拍回数 |
| 5 | コピー/ペースト | スロット設定と全パート情報をコピー |
| 6 | 全てのノートを削除 | このスロットのノートデータを削除 |

## 演奏モードの種類

### コードモード（通常）
ルートボタンとコード種ボタンでコードを演奏します。

### ノートモード
プレイボタン1つずつに音程が割り当てられます。鍵盤のように使えます。

使えるスケール：
- **Penta**：ペンタトニックスケール
- **Major**：メジャースケール
- **Chrome**：クロマチックスケール
- **Blues**：ブルーススケール
- **Japan**：日本音階

スケール変更：演奏画面でシフトレバーを操作しながらプレイボタン最下段を押す

### ドラムモード
プレイボタン1つずつにドラムの音が割り当てられます。

## ステップ／ビートの設定

1拍の中に何回裏拍を入れるかの設定です：

| 値 | 動作 |
|---|---|
| 1 | ボタン1回押しで半拍分進む |
| 2 | 押す・離すそれぞれで1ステップ（標準） |
| 3 | 3連符のように演奏 |
| 4 | 4連符のように演奏 |
