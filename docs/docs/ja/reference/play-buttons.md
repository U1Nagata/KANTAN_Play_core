# 演奏ボタンの使い方

## 基本的な演奏

**ルートボタン**（左3列）をリズムに合わせて押すと、コードが鳴ります。

ボタンの数字はコードの度数（スケール上の位置）を表します：

```
[7] [8] [9]   ← 8=フラット(♭)、9=シャープ(♯)の役割
[4] [5] [6]
[1] [2] [3]
```

!!! tip "半音ずらす"
    8または9を押しながらルートボタンを押すと、音を半音ずらせます。

## コード種ボタン（右2列）

コード種ボタンを押しながらルートボタンを押すと、コードの種類が変わります：

| ボタン | コード種 | 説明 |
|---|---|---|
| 右端・上 | sus4 | サスフォー |
| 右端・中 | M7 | メジャーセブンス |
| 右端・下 | add9 | アドナインス |
| 右から2列目・上 | dim | ディミニッシュ |
| 右から2列目・中 | 7th | セブンス |
| 右から2列目・下 | 〜 | スワップ（メジャー⇔マイナー反転） |

## キーを変える

**ジョグダイヤル**を回すと、その場でキー（調）が変わります。

## 音を止める

上ダイヤルを押すと、鳴っている音を全て止めます。
