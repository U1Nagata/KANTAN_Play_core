# 設定メニュー一覧

メニューは**左サイドボタン**または**下ダイヤルを押す**と開きます。

## メニューの操作方法

| 操作 | 動作 |
|---|---|
| 下ダイヤルを回す / 上下ボタン | カーソルを上下に移動 |
| 下ダイヤルを押す / 右サイドボタン | 決定・サブメニューへ進む |
| 左サイドボタン | キャンセル・ひとつ上に戻る |
| **数字ボタンを押す** | 番号で直接項目にジャンプ |

!!! tip "数字ボタンで素早く移動"
    メニューが開いている状態でプレイボタンの数字を押すと、その番号の項目にカーソルが飛びます。
    例：メニューを開いて `3` を押すと「コード進行」にジャンプします。

## 各メニュー項目の詳細

### 1. ジャンル

ジャンルプリセットを選んでコード進行を読み込みます。
読み込んだコード進行は「仮のデータ」として扱われます。保存したい場合は **2. ソング → 2. ソングを保存** で保存してください。

| 番号 | 項目名 |
|---|---|
| 1 | ポップス |
| 2 | ロック |
| 3 | ダンス |
| 4 | ファンク |
| 5 | R&B |
| 6 | ジャズ |
| 7 | ラテン |
| 8 | アコースティック |
| 9 | バラード |
| 10 | 特殊リズム |

---

### 2. ソング

| 番号 | 項目名 | 説明 |
|---|---|---|
| 1 | ソングを開く | ソングファイルを選んで読み込む |
| 1-1 | プリセットソング | 本体内蔵のプリセット曲 |
| 1-2 | ユーザソング(SD) | SDカードに保存したユーザー曲 |
| 1-3 | エクストラソング(SD) | SDカードのエクストラフォルダの曲 |
| 2 | ソングを保存 | 現在のソングをSDカードに保存 |
| 3 | ソング管理 | Wi-Fi経由でファイルを管理（ソングマネージャー） |
| 4 | ソングデータリセット | ソングデータを初期状態に戻す |

---

### 3. コード進行

| 番号 | 項目名 | 説明 |
|---|---|---|
| 1 | コード進行を開く | 保存済みのコード進行を読み込む |
| 1-1 | プリセットを開く | プリセットのコード進行 |
| 1-2 | ユーザデータ(SD) | SDカードに保存したコード進行 |
| 2 | コード進行を保存 | 現在のコード進行をSDカードに保存 |
| 3 | レコーディング | コード進行の録音を開始 |
| 4 | コード進行をリセット | コード進行を初期状態に戻す |

---

### 4. プレイモード

| 番号 | モード名 | 説明 |
|---|---|---|
| 1 | フリープレイ | ガイドなし。自由に演奏 |
| 2 | ビートプレイ | ガイドなし。ビートに合わせて演奏 |
| 3 | ガイドプレイ | コード進行に従いガイド表示。タイミングはかんぷれが決める |
| 4 | フリーガイド | ガイドは表示されるが、タイミングは自分で決める |
| 5 | オートソング | 全自動演奏 |

---

### 5. 編集

#### 5-1. テンポ＆グルーヴ設定

| 番号 | 項目名 | 説明 |
|---|---|---|
| 1 | テンポ(BPM) | 曲のテンポ |
| 2 | スウィング | リズムのスウィング感（跳ね感） |
| 3 | 裏拍演奏 | 裏拍のタイミングでの演奏スタイル |
| 4 | ステップ／ビート | 1拍あたりの裏拍回数（ソング全体に適用） |

#### 5-2. スロット設定

| 番号 | 項目名 | 説明 |
|---|---|---|
| 1 | スロット数 | 使用するスロットの総数（最大64） |
| 2 | 演奏モード | コード / ノート / ドラム |
| 3 | キー転調 | このスロットだけキーをずらす量 |
| 4 | ステップ／ビート | 1拍あたりの裏拍回数（スロット個別設定） |
| 5 | コピー/ペースト | スロット設定と全パート情報をコピー |
| 6 | 全てのノートを削除 | このスロットのノートデータをすべて削除 |

---

### 6. システム

#### 6-1. WiFi通信

| 番号 | 項目名 | 説明 |
|---|---|---|
| 1 | Webサーバ | Wi-Fiでソング管理サーバーを起動 |
| 2 | ファーム更新 | Wi-Fiでファームウェアを更新 |
| 3 | WiFi設定 | Wi-FiのSSID・パスワードを設定 |

#### 6-2. 操作マッピング

各ボタン・入力に機能を割り当てます。

- **マッピング1（本体）**：本体の設定として保存。全ソング共通で有効。
- **マッピング2（ソング）**：ソングファイルごとに保存。曲ごとに異なる割り当てが可能。

| 番号 | 項目名 | 内容 |
|---|---|---|
| 1 | プレイボタン | 1〜15のプレイボタンに機能を割り当て |
| 2 | スロットボタン | 1〜4のスロットボタンに機能を割り当て |
| 3 | 拡張入力 | 外部スイッチ入力1〜32に機能を割り当て |
| 4 | MIDI Note | 受信したMIDIノートナンバーに機能を割り当て |

マッピング2（ソング）のみ追加で以下が使用可能：

| 番号 | 項目名 | 内容 |
|---|---|---|
| 5 | マッピング1からコピー | 本体マッピングの設定をソングにコピー |
| 6 | マッピング消去 | このソングのマッピングを削除 |

#### 6-3. 外部デバイス

| 番号 | 項目名 | 説明 |
|---|---|---|
| 1 | ポートC MIDI | Grove ポートCでのMIDI接続設定 |
| 2 | BLE MIDI | Bluetooth MIDI接続設定 |
| 3 | USB | USB接続設定 |
| 3-1 | USBモード設定 | USBの動作モード |
| 3-2 | ホスト給電設定 | USBホスト給電のオン/オフ |
| 3-3 | USB MIDI | USB MIDI機能のオン/オフ |
| 4 | インスタコードリンク | インスタコードとの連携設定 |
| 4-1 | 接続方法 | 接続するポートを選択 |
| 4-2 | 演奏デバイス | リンク時の演奏担当デバイス |
| 4-3 | 演奏スタイル | リンク時の演奏スタイル |

#### 6-4. ベロシティ(強弱)

| 番号 | 項目名 | 説明 |
|---|---|---|
| 1 | 本体ボタン | 本体ボタンのベロシティ（音の強弱）設定 |
| 2 | 外部MIDI入力 | 外部MIDI入力のベロシティ設定 |

#### 6-5. 表示

| 番号 | 項目名 | 説明 |
|---|---|---|
| 1 | 画面の輝度 | ディスプレイの明るさ |
| 2 | LEDの輝度 | LEDの明るさ |
| 3 | 詳細表示 | 詳細情報の表示オン/オフ |
| 4 | 波形表示 | 音の波形表示のオン/オフ |

#### 6-6〜10. その他システム設定

| 番号 | 項目名 | 説明 |
|---|---|---|
| 6 | 言語 | 表示言語の切り替え（日本語 / English） |
| 7 | ガイド音 | メニュー操作・パート切替時の音声フィードバック |
| 8 | 音量 | マスター音量設定 |
| 8-1 | MIDIマスター音量 | MIDI全体の音量 |
| 8-2 | ADCマイクアンプ | マイク入力のアンプゲイン |
| 9 | システム情報 | ファームウェアバージョンなどを表示 |
| 10 | 全設定リセット | 全ての設定を工場出荷時に戻す |

---

### 7. Webマニュアル

このオンラインマニュアルへのQRコードを表示します。
