### ボタン配置（正面）

**スロットボタン（最上段4つ）**
演奏パターンを切り替えます。特定のスロットにジャンプする機能が割り当てられます。

**プレイボタン（3行×5列＝15個）**

- 左3列（ルートボタン）：コードのルート音の度数（1〜7）を指定
- 右2列（コード種ボタン）：コードの種類を指定

| ボタン位置 | 機能 |
|---|---|
| 右端列（上から）| sus4 / M7 / add9 |
| 右から2列目（上から）| dim / 7th / 〜（スワップ） |

**ダイヤル（上）**
- 回す：音量調整
- 押す：音を止める

**ダイヤル（下）**
- 押す：設定メニューを開く
- メニュー中に回す：カーソルを上下に移動
- メニュー中に押す：項目を決定

## 側面・背面

**電源ボタン**：本体上面右側。長押しで電源オン/オフ。

**USB端子（USB-C）**：本体上面中央。充電・通信用。

**イヤホン端子**：本体下面中央。

**シフトレバー**：本体右上。上下に動かす・押し込むの3操作が可能。
通常操作と異なる機能を呼び出します。

**右サイドボタン**：自動演奏モードの切り替え。メニュー中は「決定」。

**左サイドボタン**：設定メニューを呼び出す。メニュー中は「キャンセル」。

**ジョグダイヤル**：本体左側面上側。曲のキー（調）を変更。

**TFカードスロット**：ジョグダイヤルの近く。microSDカード用。

**Grove Port（グローブポート）**：本体上面の四角い端子3つ。
- ポートA（表面側左）：I2C通信
- ポートB（裏面側左）：GPIO通信
- ポートC（裏面側右）：UART通信（外部スイッチ接続など）
