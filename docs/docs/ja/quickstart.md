# クイックスタート

かんぷれを初めて使う方向けの手順です。電源を入れてから最初の音が出るまでを説明します。

---

## 1. 充電する

USBケーブルで充電してください。本体上面中央のUSB-C端子に接続します。

!!! warning "購入直後は必ずアップデートを"
    最新ファームウェアにアップデートしないと、一部の機能が使えません。先にアップデートを完了させてください。

---

## 2. 電源を入れる

本体上面右側の**電源ボタンを長押し**すると電源が入ります。

- 画面にロゴが表示されたら起動完了です

---

## 3. ファームウェアをアップデートする

初回は必ずアップデートしてください。

**Wi-Fiでアップデートする場合（推奨）**

1. メニューを開く（左サイドボタン または 下ダイヤルを押す）
2. **[Menu 6-1-3] システム → WiFi通信 → WiFi設定** でWi-Fiを設定
3. **[Menu 6-1-2] システム → WiFi通信 → ファーム更新** を実行

詳細は [Wi-Fiでアップデート](update/wifi.md) を参照してください。

---

## 4. 最初の音を出してみる

アップデートが完了したら、演奏してみましょう。

1. 画面下部の**プレイボタン（左側3列）**をリズムに合わせて押す
2. コードが鳴ります！

ボタンの配置については [演奏ボタンの使い方](reference/play-buttons.md) を参照してください。

---
