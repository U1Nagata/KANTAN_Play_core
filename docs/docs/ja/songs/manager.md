# ソングマネージャーの使い方

ソングマネージャーを使うと、スマホやPCのブラウザからSDカード内のファイルを管理できます。SDカードを取り出す必要がありません。

## 起動方法

**[Menu 2-3] ソング → ソング管理**

1. メニューを開く（左サイドボタン または 下ダイヤル押し）
2. **[Menu 2] ソング** を選択
3. **[Menu 2-3] ソング管理** を選択
4. かんぷれとスマホ/PCを同じWi-Fiネットワークに接続する
5. 画面に表示されたURLをブラウザで開く

!!! tip "Wi-Fiの設定がまだの場合"
    先に **[Menu 6-1-3] システム → WiFi通信 → WiFi設定** でWi-Fiを設定してください。

## できること

- ソングファイルの一覧表示・ダウンロード・削除
- ソングファイルのアップロード
- ファイル名の変更
- MIDIファイルへの変換
