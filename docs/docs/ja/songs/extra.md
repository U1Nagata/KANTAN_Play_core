# エクストラソングのダウンロード

エクストラソングは、WEBからダウンロードできる追加の曲データです。
旧ファームウェアに収録されていたソングも含まれています。

## ダウンロード方法

1. [エクストラソング配布ページ](#) にアクセス
2. ダウンロードしたファイルをSDカードの `extra/` フォルダに入れる
   または [ソングマネージャー](manager.md) からアップロード

## 使い方

**[Menu 2-1-3] ソング → ソングを開く → エクストラソング(SD)**

1. メニューを開く（左サイドボタン または 下ダイヤル押し）
2. **[Menu 2] ソング** を選択
3. **[Menu 2-1] ソングを開く** を選択
4. **[Menu 2-1-3] エクストラソング(SD)** を選択
5. 曲一覧から番号で選んで決定
