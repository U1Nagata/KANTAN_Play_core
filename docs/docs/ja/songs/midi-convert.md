# MIDIファイル変換

録音したコード進行をMIDIファイルに変換してDAWに取り込めます。

## 変換方法

**[Menu 2-3] ソング → ソング管理** でソングマネージャーを起動

1. メニューを開く（左サイドボタン または 下ダイヤル押し）
2. **[Menu 2] ソング** を選択
3. **[Menu 2-3] ソング管理** を選択してソングマネージャーを起動
4. かんぷれとスマホ/PCを同じWi-Fiネットワークに接続する
5. 画面に表示されたURLをブラウザで開く
6. 変換したいソングを選択して「MIDIに変換」を実行
7. 生成されたMIDIファイルをダウンロード

変換されたMIDIファイルはDAWソフト（GarageBand、Logic Pro、Ableton Liveなど）で開けます。
