# KANTAN Play core マニュアル

**KANTAN Play core（かんぷれ）**へようこそ。

かんぷれは、音楽の知識がなくても楽しめるMIDIシーケンサー兼楽器ガジェットです。

---

## あなたの使い方は？

<div class="grid cards" markdown>

-   ## 🎵 創る

    楽曲を作りたい・伴奏トラックを作りたい方向け

    ジャンルを選んでコード進行を作り、録音して保存できます。
    シンガーソングライターの編曲にも最適です。

    [→ 創るガイドへ](create/index.md){ .md-button .md-button--primary }

-   ## 🎸 演奏する

    弾き語り・複数トラック同時演奏・ゲーム感覚で楽しみたい方向け

    コード譜を見ながら演奏したり、プリセットソングを6パート同時演奏で楽しめます。

    [→ 演奏するガイドへ](play/index.md){ .md-button .md-button--primary }

</div>

---

## はじめての方へ

まず[クイックスタート](quickstart.md)で電源投入からアップデート、最初の音が出るまでの手順を確認してください。
