# 外部スイッチで操作する

フットスイッチなどの外部スイッチをGroveポートに接続して、ハンズフリー操作ができます。

## 接続方法

Grove ポートB（本体上面、裏面側左）に接続します。

## 機能の割り当て

接続した外部スイッチに機能を割り当てます：

**[Menu 6-2-1-3] システム → 操作マッピング → マッピング1（本体）→ 拡張入力**

1. メニューを開く（左サイドボタン または 下ダイヤル押し）
2. **[Menu 6] システム** を選択
3. **[Menu 6-2] 操作マッピング** を選択
4. **[Menu 6-2-1] マッピング1（本体）** を選択
5. **[Menu 6-2-1-3] 拡張入力** を選択
6. 割り当てたい入力番号（1〜32）を選択して機能を設定

最大32個の外部入力に対して機能を割り当てられます。
