# MIDIキーボード等と接続

MIDIキーボードや他のMIDI機器を接続できます。

## 接続方法

### USB MIDI

USBケーブルで接続します。

**[Menu 6-3-3-3] システム → 外部デバイス → USB → USB MIDI** でオン/オフを設定

### BLE MIDI（Bluetooth）

Bluetooth経由でMIDI機器と無線接続できます。

**[Menu 6-3-2] システム → 外部デバイス → BLE MIDI** で設定

### ポートC MIDI

Grove ポートCを使ってMIDI機器と接続できます。

**[Menu 6-3-1] システム → 外部デバイス → ポートC MIDI** で設定
