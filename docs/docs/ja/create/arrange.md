# 自分の曲に伴奏をつける

思いついたメロディにコード進行を見つけたい方向けの使い方です。

## 手順

### 1. ジャンルを選ぶ

1. メニューを開く（左サイドボタン または 下ダイヤル押し）
2. **[Menu 1] ジャンル** → 自分の曲に合いそうなジャンルを番号で選ぶ

### 2. コードを探る

プレイボタン（左3列）をポチポチ押して、メロディに合うコードを探します。

- ボタン1〜7がコードの度数（1=Ⅰ、2=Ⅱ...）に対応
- ジョグダイヤルでキー（調）を変えられます

!!! tip "キーを変えるには"
    本体左側面のジョグダイヤルを回すと、その場でキーが変わります。
    メロディのキーに合わせてから弾いてみましょう。

### 3. コード進行をレコーディング

合う進行が見つかったらレコーディングして記録します。

1. **[Menu 3-3] コード進行 → レコーディング** を選択
2. 演奏しながらコード進行を録音する

[→ レコーディングして保存](recording.md)
