# 創る

かんぷれは、音楽理論がわからなくても**ジャンルを選ぶだけ**でコード進行のベースを作れます。

## こんな使い方ができます

### 楽曲のプロットを作りたい
1. ジャンルを選ぶ
2. シーケンス（コード進行）を選ぶ
→ これだけで曲の骨格が完成します

[→ ジャンルでコード進行を作る](genre.md)

### 自分のメロディに伴奏をつけたい（シンガーソングライター向け）
1. ジャンルを選んでプレイボタンをポチポチ試す
2. 気に入ったコード進行が見つかったらレコーディング
3. 保存してガイドプレイで確認

[→ 自分の曲に伴奏をつける](arrange.md)

### 作ったデータをDAWで使いたい
レコーディングしたコード進行をMIDIファイルに変換できます。

[→ MIDIファイルに変換](midi-export.md)
