# レコーディングして保存

コード進行をレコーディングすると、後でガイドプレイとして使えます。

## レコーディングの開始

**[Menu 3-3] コード進行 → レコーディング**

または

**[Menu 5-3] 編集 → レコーディング**

## レコーディング中の操作

録音中にメニューを開くと専用のレコーディングメニューが表示されます：

| 番号 | 項目 | 内容 |
|---|---|---|
| 1 | ジャンプ | |
| 1-1 | 先頭へ移動 | カーソルをシーケンスの先頭に戻す |
| 1-2 | 末尾へ移動 | カーソルをシーケンスの末尾に移動 |
| 2 | 拡張・圧縮 | |
| 2-1 | 200%に拡張 | シーケンスの長さを2倍に伸ばす |
| 2-2 | 50%に圧縮 | シーケンスの長さを半分に縮める |
| 3 | カーソル後をクリア | カーソル位置以降のデータを削除 |
| 4 | プレイモード | プレイモードの切り替え |
| 5 | レコーディング終了 | 録音を終了して通常モードに戻る |
| 6 | 詳細設定 | メインメニューへ |

## コード進行を保存する

録音したコード進行を別途保存できます：

**[Menu 3-2] コード進行 → コード進行を保存**

保存したデータはSDカードの `progressions/` フォルダに保存されます。

## ソングを保存する

音色・パターンなどソング全体のデータを保存する場合：

**[Menu 2-2] ソング → ソングを保存**
または
**[Menu 5-4] 編集 → ソングを保存**
