# MIDIファイルに変換

録音したコード進行をMIDIファイルに変換してDAWに取り込めます。

## 操作手順

1. **[Menu 2-3] ソング → ソング管理** を選択してソングマネージャーを起動
2. かんぷれとスマホ/PCを同じWi-Fiネットワークに接続する
3. 画面に表示されたURLをブラウザで開く
4. 変換したいソングを選択して「MIDIに変換」を実行
5. 生成されたMIDIファイルをダウンロード

変換されたMIDIファイルはDAWソフト（GarageBand、Logic Pro、Ableton Liveなど）で開けます。

詳細は [ソングマネージャー](../songs/manager.md) を参照してください。
