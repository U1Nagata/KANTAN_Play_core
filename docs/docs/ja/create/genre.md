# ジャンルでコード進行を作る

ジャンルプリセットを使うと、プロが作ったコード進行パターンをすぐに読み込めます。

## 操作手順

1. メニューを開く（左サイドボタン または 下ダイヤル押し）
2. **[Menu 1] ジャンル** を選択
3. 使いたいジャンルを番号で選ぶ

### 選べるジャンル

| 番号 | ジャンル |
|---|---|
| 1 | ポップス |
| 2 | ロック |
| 3 | ダンス |
| 4 | ファンク |
| 5 | R&B |
| 6 | ジャズ |
| 7 | ラテン |
| 8 | アコースティック |
| 9 | バラード |
| 10 | 特殊リズム |

4. ジャンルを選ぶとシーケンス一覧が表示される
5. 番号を押して気に入ったシーケンスを選択すると読み込まれる

!!! tip "仮読み込みについて"
    ジャンルから読み込んだコード進行は「仮のデータ」として扱われます。
    保存したい場合は **[Menu 2-2] ソング → ソングを保存** で保存してください。
