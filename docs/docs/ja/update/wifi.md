# Wi-Fiでアップデート

Wi-Fiを使って、かんぷれ本体だけでアップデートできます。PCは不要です。

## 手順

### 1. Wi-Fiを設定する（初回のみ）

**[Menu 6-1-3] システム → WiFi通信 → WiFi設定**

1. メニューを開く（左サイドボタン または 下ダイヤルを押す）
2. **[Menu 6] システム** を選択
3. **[Menu 6-1] WiFi通信** を選択
4. **[Menu 6-1-3] WiFi設定** を選択
5. 接続するWi-FiのSSIDとパスワードを入力して保存

### 2. アップデートを実行する

**[Menu 6-1-2] システム → WiFi通信 → ファーム更新**

1. **[Menu 6] システム** → **[Menu 6-1] WiFi通信** → **[Menu 6-1-2] ファーム更新** を選択
2. 最新バージョンが表示されたら「更新」を選択
3. ダウンロードとインストールが始まります（数分かかります）
4. 完了すると自動で再起動します

!!! warning "アップデート中は電源を切らないでください"
    アップデート中に電源が切れると、本体が起動しなくなる場合があります。
    充電しながら実行することをおすすめします。
