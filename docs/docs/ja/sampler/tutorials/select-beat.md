# Beatを選ぶ

Beatは、演奏の速さとLoopの長さを決める土台です。内蔵Pattern、SDカードのWAV / MP3 / MIDI、またはSampler Padの音を使えます。

最初は内蔵Patternから選ぶのがおすすめです。

## 1. BEATパートを選ぶ

1. 右側の下のダイヤルを回します
2. パート選択から`BEAT`を選びます
3. 下のダイヤルを押してメニューを開きます
4. `Beat` → `Select Beat`へ進みます

<!-- IMAGE BEAT-01: BeatメニューのSelect Beatが選択されている画面。 -->

## 2. Beatの場所を選ぶ

| 選択肢 | 内容 |
|---|---|
| `Built-in` | Pop、Rock、House、Hip Hop、Disco、Breakなどの内蔵Pattern |
| `SD Card` | SDカードに保存したWAV、MP3、MID、MIDI |
| `Sampler Pad` | 現在のSampler Padを独立したAudio Beatにする |

初めての場合は`Built-in`を選びます。

## 3. 試聴して決める

1. 下のダイヤルを回して候補を選びます
2. `Fn1`でPreviewします
3. 別の候補を聴く場合は、ダイヤルを回してからもう一度`Fn1`を押します
4. 気に入ったBeatで`OK`を押します

Patternは元のTempoで1周、WAV / MP3は短い範囲がPreviewされます。Previewだけでは現在のProjectは変更されません。

## Rec済みの演奏がある場合

Beatを変更すると、現在のRecをどう扱うか選ぶ画面が表示されることがあります。

| 選択肢 | 結果 |
|---|---|
| `Follow New Beat` | Recした演奏位置を、新しいBeatの長さに合わせる |
| `Keep Current Tempo` | 現在のLoop長を保ち、Beat側を現在の速さへ合わせる |
| `Clear Rec` | Recした演奏を消し、新しいBeatを基準にする |

迷った場合は`Follow New Beat`を選びます。今の演奏を消したくない場合は`Clear Rec`を選ばないでください。

## Patternの音色を変える

Pattern Beatでは、`Beat` → `Select Kit`からドラム音色を選べます。

- `Acoustic`
- `Dance`
- `Chiptune`

PatternとTempoを変えずに、ドラムの音色だけを交換できます。

## Beatの音量と繰り返し

Beatメニューでは次も調整できます。

- `Beat Volume`：Beatの音量
- `Beat Repeat`：Beatを1回、2回、4回繰り返してLoopの長さにする

Beat Repeatを変更すると、Recの基準となるLoop長も変わります。
