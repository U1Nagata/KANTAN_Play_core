# 演奏をRecする

RECモードでは、Padを押したタイミングを記録し、同じ演奏をLoopとして繰り返せます。

最初はBeatを鳴らしながら、Samplerの2音だけをRecしてみましょう。

## 1. Beatを用意する

Beatが決まっていない場合は、内蔵Patternを1つ選びます。

[Beatを選ぶ](select-beat.md){ .md-button }

## 2. SAMPLERのRECモードにする

1. パートを`SAMPLER`にします
2. 4つの黒いモードボタンから`REC`を押します
3. Beatが止まっている場合は`Fn1`を押します

画面の演奏表示エリアが、Recした位置を示す表示に変わります。

<!-- IMAGE LOOP-01: SAMPLER + REC。Beat再生中で、まだRecイベントがない画面。 -->

## 3. Pad演奏を記録する

1. Beatを1周聴きます
2. 気に入ったSample Padを1回押します
3. 次の周回で、別の位置にもう1音加えます
4. 何も押さずに次の周回を聴きます

自分が押さなくても同じ音が鳴れば、Recできています。画面には、Recした位置がPadごとの印として表示されます。

<!-- IMAGE LOOP-02: 2〜4個のSamplerイベントが記録されたREC画面。 -->

## 4. 間違えたらUndoする { #undo }

直前のRecを戻すには、`Fn3`を短く押して離します。

Undoの履歴はパートごとに管理されます。別のパートへ移動すると、そのパートで保持していたUndo履歴は破棄されます。

!!! warning
    `Fn3`を長押しすると、現在のパートにRecした演奏をまとめて消します。短押しのUndoと間違えないようにしてください。

## 特定のPadだけを消す

RECモードで`Fn3`を押したまま、消したいPadを押します。そのPadのRecだけを削除できます。

この個別削除はUndoできません。対象Padを確認してから操作してください。

## Recした演奏を一時的にMuteする

- `Fn2`を短く押す：現在パートのRecをMute / Unmute
- `Fn2`を押したままPadを押す：そのPadのRecだけをMute / Unmute

Mute中も、手で押した生演奏は鳴ります。記録済み演奏を止めて、その場の演奏へ切り替えられます。

## 別のパートを重ねる

Loopを止めずにパートを切り替え、同じ手順で音を重ねられます。

おすすめの順番：

1. `SAMPLER`
2. `BASS`
3. `MELODY`
4. `CHORD`

最初から全部使う必要はありません。SamplerとBassだけでも十分に曲らしくなります。

## BeatなしでLoopを作る

BeatもRecもない状態では、最初にPadを押した位置から記録が始まります。

1. `REC`モードで最初の音を押します
2. 好きな長さまで演奏します
3. `Fn1 END`を押します

最初の音からENDまでが新しいLoop長になります。

## 演奏を止める

- `Fn1`：Loopを停止。もう一度押すと先頭から再生
- 上のダイヤルを押す：すべての音とLoopを停止
