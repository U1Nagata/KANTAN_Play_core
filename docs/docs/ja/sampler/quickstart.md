# はじめての5分

このページでは、初期状態のKANTAN Samplerを使って、Sampleを鳴らし、Beatに合わせて演奏するところまで進みます。最後に、その演奏をRecして残します。

## 始める前に

- 本体の電源を入れます
- 最初は音量を小さめにします。右側の**上のダイヤル**を回すと全体の音量を調整できます
- 音をすべて止めたいときは、右側の**上のダイヤルを押し込みます**

![SAMPLERパートのPLAY画面を表示したKANTAN Sampler実機](assets/images/device-play-overview.jpg){ .device-photo loading=lazy }

写真のように、画面上部へ`SAMPLER`、モード欄へ`PLAY`が表示されていれば準備完了です。

表示が違う場合は、次のように戻します。

1. 右側の下のダイヤルを回し、パート選択から`SAMPLER`を選びます
2. 画面下にある4つの黒いモードボタンのうち、左から2番目の`PLAY`を押します

## 1. 8つのSampleを鳴らす

大きな白いボタンは、左4列が演奏用Padです。初期状態では、上2段の8つのPadにSampleが入っています。

1. 上2段、左4列のPadを1つずつ短く押します
2. Padごとに違う音が鳴ることを確認します
3. 気に入った2つか3つの音を覚えます

!!! tip "ここでのゴール"
    上手に演奏する必要はありません。押したPadから音が鳴れば成功です。

下段の4つは初期状態では空です。押しても音が鳴らない場合がありますが、故障ではありません。

## 2. Beatを再生する

白いボタンの右端1列は`Fn`ボタンです。一番上の`Fn1`には、画面上で再生マークが表示されています。

1. 右端列の一番上にある`Fn1`を押します
2. Beatが繰り返し再生されることを確認します
3. もう一度`Fn1`を押すと停止します

!!! note
    ここで鳴るリズムの土台を**Beat**と呼びます。BeatそのものをLoopとは呼びません。

## 3. Beatに合わせてPadを押す

1. `Fn1`を押してBeatを再生します
2. 先ほど覚えたSampleを、Beatを聴きながら自由に鳴らします
3. 同じ音を繰り返したり、2つの音を交互に鳴らしたりしてみます

タイミングが多少ずれても問題ありません。Beatが鳴っているだけで、ばらばらだった音が演奏らしく聞こえてきます。

## 4. 演奏をRecして残す

次は、今の演奏を本体に覚えさせます。

1. 4つの黒いモードボタンから、左から3番目の`REC`を押します
2. Beatが止まっている場合は`Fn1`を押して再生します
3. Beatを聴きながらSample Padをいくつか押します
4. 同じ場所まで戻ると、先ほどの演奏が自動的に繰り返されます

このRecした演奏データと、その繰り返し再生を**Loop**と呼びます。

## 5. 間違えたらUndoする

RECモードで直前の操作を戻すには、右端列の一番下にある`Fn3`を短く押して離します。

!!! warning
    `Fn3`の長押しは、現在のパートに記録した演奏をまとめて消す操作です。Undoしたいときは短く押してください。

## 最初の体験は完了です

ここまでで、次の違いを体験できました。

- Sample：自分でPadを押したときに鳴る音
- Beat：演奏の土台として繰り返すリズム
- Rec：自分の演奏を記録する操作
- Loop：記録された演奏の繰り返し

次は、目的に合わせて進みます。
