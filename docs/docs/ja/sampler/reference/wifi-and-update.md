# Wi-FiとUpdate

Wi-FiはFile EditorとファームウェアUpdateに使います。通常の演奏中は常時接続する必要はありません。

## スマートフォンでWi-Fiを設定する

1. 下のダイヤルを押してメニューを開きます
2. `Wi-Fi` → `Wi-Fi Setup` → `Use Smartphone`へ進みます
3. 本体画面のQRコードをスマートフォンで読み取ります
4. 表示された`kanplay-ap`へ接続します
5. 本体画面が設定ページ用QRコードへ切り替わるまで待ちます
6. 新しいQRコードを読み取り、自宅などのWi-Fi名とPasswordを送信します
7. 本体に接続結果が表示されるまで待ちます

<!-- IMAGE WIFI-01: Use Smartphone中の接続用QR、SSID、Passwordが読める。 -->

スマートフォンが「インターネットに接続されていません」と表示しても、設定中は正常です。`kanplay-ap`との接続を維持してください。

## WPSで設定する

WPS対応ルーターの場合は、`Wi-Fi Setup` → `WPS`を選び、ルーター側のWPSボタンを操作します。接続結果が表示されるまで本体の電源を切らないでください。

## 接続情報を確認する

`Wi-Fi` → `Wi-Fi Info`で、接続状態やアドレスを確認できます。

## File Editorを開く

`Wi-Fi` → `File Editor`を選び、本体のQRコードまたはアドレスを同じWi-Fi上のPC・スマートフォンで開きます。

[File Editorの使い方](file-editor.md){ .md-button .md-button--primary }

## ファームウェアをUpdateする

1. 電源を安定して供給します
2. Wi-Fiへ接続します
3. `Wi-Fi` → `Update`を選びます
4. 画面の進捗が完了し、本体が通常画面へ戻るまで待ちます

更新が見つかると、ステータスバーに黄色の`UP!`が表示されます。

<!-- IMAGE WIFI-02: UP!表示またはUpdate進捗画面。 -->

!!! danger
    ファームウェアの書き込み開始後は、電源を切ったりUSBケーブルを抜いたりしないでください。

接続中やダウンロード開始前など、安全に中止できる段階では本体操作で中断できます。書き込み開始後は操作を受け付けません。

## Auto Updateについて

`Wi-Fi` → `Auto Update`をONにすると、保存済みWi-Fiがある場合に起動後のアイドル時へ更新の有無を確認します。自動で書き換える設定ではありません。更新実行は`Update`から行います。

## 接続できない場合

- PC・スマートフォンと本体が同じWi-Fiか確認する
- ゲストWi-Fiや端末間通信を禁止する設定を避ける
- 本体をアクセスポイントの近くへ移動する
- `Wi-Fi Setup`をやり直す
- File Editorを開いていた場合は、本体操作で終了してから再度開く
