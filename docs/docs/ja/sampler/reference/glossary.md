# 用語集

## 基本の5用語

| 用語 | 意味 |
|---|---|
| `Sample` | Padへ割り当てて鳴らす音 |
| `Beat` | リズムの土台。Pattern、または繰り返し再生するWAV / MP3 |
| `Rec` | Pad演奏のタイミングを記録する機能 |
| `Loop` | Recで記録した演奏データと、その繰り返し再生 |
| `Music` | Music Playerで再生する曲全体のWAV / MP3 |

BeatとLoopは別のものです。Beatは演奏の土台、LoopはRecした演奏です。

## Sampleと音作り

| 用語 | 意味 |
|---|---|
| `Start / End` | Sampleを鳴らす範囲の始点と終点 |
| `Pitch` | Sampleの音程と再生速度 |
| `Hold` | Padを押している間だけ音を鳴らす設定 |
| `Sample Repeat` | 1つのSampleをWhole SampleまたはGrid単位で繰り返す機能 |
| `Reverse` | Sampleの逆再生 |
| `Choke` | 新しい音で、同じグループの前の音を止める機能 |
| `Chop` | 長いSampleを複数の短いSampleへ分ける機能 |
| `Slice` | Chopによって作られた1つずつの短いSample |
| `Sustain Loop` | Sample Synthで波形の一部分を循環させ、音を伸ばす機能 |
| `Release` | Padを離したあと、音が消えるまでの長さ |
| `Pad Base Note` | Sampleが元々持つ基準音程 |

Sustain Loopは音色を伸ばす内部の繰り返しで、Recによる演奏のLoopとは別です。

## Beatとタイミング

| 用語 | 意味 |
|---|---|
| `Pattern Beat` | 短いドラム音と演奏パターンで作るBeat |
| `Audio Beat` | WAV / MP3を繰り返して使うBeat |
| `Tempo` | 演奏の速さ |
| `Grid` | Loop全体を等分したタイミングの目盛り |
| `Quantize` | Pad入力を近いGridへ合わせる機能 |
| `Note Grid` | Recで音を合わせる細かさ |
| `Swing` | 交互のタイミングをずらして跳ねたリズムにする機能 |
| `Beat Repeat` | Beatを1回、2回、4回繰り返してRec Loopの長さにする設定 |
| `FIT` | Chop素材を現在のBeatまたはLoopの長さへ合わせる方式 |
| `KEEP` | Chop素材の元の速度と音程を保つ方式 |

## 演奏と保存

| 用語 | 意味 |
|---|---|
| `Mute` | 記録済みの演奏を一時的に鳴らさない機能。生演奏は鳴る |
| `Undo` | 現在パートの直前のRec操作を戻す機能 |
| `Mixer` | パートごとの一時音量とMuteを操作する画面 |
| `Mix 1〜4` | Mixerの音量とMute状態を保存して呼び出すSlot |
| `FX Target` | FXをかける対象 |
| `LIVE` | Music読込中の、Beat＋Sampler＋Bass＋Melody＋Chord |
| `MUSIC` | Music Playerで再生する曲 |
| `Performance Recording` | FXを含む最終演奏を1本のWAVへ録音する機能 |
| `Sample Kit` | 12個のSampler音源とPad編集設定のセット |
| `Project` | Sample、Beat、Rec、音楽設定、FX、Mixerを含む曲全体の保存単位 |
| `Resume` | 電源を切る前の状態を次回起動時に自動復元する仕組み |

## 音楽パート

| 用語 | 意味 |
|---|---|
| `Bass` | 曲の低音を演奏するパート |
| `Melody` | 単音の旋律を演奏するパート |
| `Chord` | 複数音の和音を演奏するパート |
| `Key` | 曲の中心となる音 |
| `Scale` | Padへ並べる音の組み合わせ |
| `Octave` | 同じ音名の高さの範囲 |
| `Pitch Bend` | 演奏中の音程を滑らかに上下する操作 |
| `Modifier` | Chordへ7th、sus4、9thなどの変化を加えるPad |

## 接続と管理

| 用語 | 意味 |
|---|---|
| `File Editor` | PCやスマートフォンからSDファイルを管理し、SampleをPadへAssignする画面 |
| `Assign` | 音や外部入力へ、Padまたは操作の役割を割り当てること |
| `Input Source` | 使用する外部コントローラーの種類 |
| `Learn` | 外部のキーやボタンを押して割り当てを覚えさせる操作 |
