# 演奏する

かんぷれは様々なスタイルで演奏を楽しめます。

## 演奏スタイルを選ぶ

### ガイドプレイで弾く
事前に録音したコード進行に従ってガイドが表示され、それを見ながら演奏できます。
楽譜が読めなくても、ガイドの指示通りにボタンを押すだけでOKです。

[→ ガイドプレイで弾く](guide-play.md)

### プリセットソングで遊ぶ
有名な曲のコード進行があらかじめ収録されています。
6パート同時演奏でゲーム感覚で楽しめます。

[→ プリセットソングで遊ぶ](preset-song.md)

### 発展的な演奏
MIDIキーボードや外部スイッチを使ったパフォーマンスも可能です。

[→ 発展的な演奏](advanced.md)
