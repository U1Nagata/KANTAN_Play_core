# プリセットソングで遊ぶ

かんぷれには有名な曲のコード進行があらかじめ収録されています。

## プリセットソングを開く

**[Menu 2-1-1] ソング → ソングを開く → プリセットソング**

1. メニューを開く（左サイドボタン または 下ダイヤル押し）
2. **[Menu 2] ソング** を選択
3. **[Menu 2-1] ソングを開く** を選択
4. **[Menu 2-1-1] プリセットソング** を選択
5. 曲一覧から番号で選んで決定

## 6パート同時演奏

プリセットソングはドラム・ベース・ギター・ピアノなど複数のパートが設定済みです。

**[Menu 4-5] プレイモード → オートソング** にすると自動演奏で全パートが鳴ります。

特定のパートをミュートしたり、音色を変えたりしてアレンジを楽しめます。

## パートのオン/オフ

画面のパートアイコンをタップすると、そのパートをオン/オフできます。

!!! tip "エクストラソングもあります"
    WEBからダウンロードできる追加の曲データ（エクストラソング）は
    **[Menu 2-1-3] ソング → ソングを開く → エクストラソング(SD)** から開けます。
    詳しくは [エクストラソングのダウンロード](../songs/extra.md) を参照してください。
