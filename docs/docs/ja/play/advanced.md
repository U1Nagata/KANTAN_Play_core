# 発展的な演奏

外部機器と組み合わせることで、より本格的な演奏が可能です。

## MIDIキーボードで演奏する

MIDIキーボードを接続すると、鍵盤でコードやメロディを演奏できます。
接続方法は **[Menu 6-3] システム → 外部デバイス** から設定します。

[→ MIDIキーボード等と接続](../connect/midi.md)

## 外部スイッチでコントロール

フットスイッチなどを使ってハンズフリーで操作できます。
弾き語りパフォーマンスに最適です。
機能の割り当ては **[Menu 6-2-1-3] システム → 操作マッピング → マッピング1（本体）→ 拡張入力** から設定します。

[→ 外部スイッチで操作する](../connect/switch.md)

## インスタコードリンク

インスタコード（別売）と連携して、より豊かな演奏表現ができます。
**[Menu 6-3-4] システム → 外部デバイス → インスタコードリンク** から設定します。

[→ インスタコードリンクの使い方](../connect/iclink.md)
