# 困ったときは

## よくある問題

### 音が出ない
- 上ダイヤルを回して音量を確認してください
- イヤホン/スピーカーが正しく接続されているか確認してください

### 画面が暗い・消えている
- **[Menu 6-5-1] システム → 表示 → 画面の輝度** で明るさを上げてください

### Wi-Fiに接続できない
- **[Menu 6-1-3] システム → WiFi通信 → WiFi設定** でSSIDとパスワードを確認してください
- 2.4GHzのWi-Fiに接続してください（5GHz非対応）

### ファームウェアの更新ができない
- Wi-Fi接続を確認してから **[Menu 6-1-2] システム → WiFi通信 → ファーム更新** を再試行してください
- [PCを使ってアップデート](../update/pc.md) をお試しください
